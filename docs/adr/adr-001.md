# ADR: Arrow Keys and WASD for Movement

## Status
Accepted

## Date
2024-01-15

## Context
The game needs a keyboard control scheme for moving the snake up, down, left, and right. The scheme must work across platforms and feel familiar to most players.

## Decision
Support both **Arrow keys** and **WASD** for the four directions.

## Alternatives Considered

- **A. Arrow keys only**  
  Familiar to casual players, but awkward for left-handed users and far from the left hand's resting position on QWERTY.

- **B. WASD only**  
  Standard in PC gaming and comfortable for left hand, but unfamiliar to non-gamers and laptop users without a numpad/arrow habit.

- **C. Arrow keys + WASD (chosen)**  
  Covers both casual and gamer audiences with minimal extra code (one key map).

- **D. Numpad (8/2/4/6)**  
  Rejected: many laptops lack a numpad.

- **E. Vim keys (hjkl)**  
  Rejected: too niche for a general audience.

## Consequences

**Positive**
- Works for both casual and experienced players.
- Zero cost to support both — just a lookup table.
- No dependency on numpad or platform-specific keys.

**Negative**
- Two bindings to document.
- Slight chance of key conflict if other features later bind `W`, `A`, `S`, `D`.

## Notes
This dual-binding scheme is a common convention in modern web and indie games.
